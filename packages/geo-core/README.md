# @askbeam/core

CMS-agnostic core of [Askbeam](https://github.com/Askbeam/Askbeam): AI crawler detection, IP verification against vendor-published ranges, hit ingestion, llms.txt builders, rich text to Markdown, and dashboard stats.

You usually don't install this directly. Use [`@askbeam/payload-plugin`](https://www.npmjs.com/package/@askbeam/payload-plugin) or [`@askbeam/strapi-plugin`](https://www.npmjs.com/package/@askbeam/strapi-plugin) with [`@askbeam/next`](https://www.npmjs.com/package/@askbeam/next).
